Notas musicais

Você escolhe as notas com números de 1 a 7 — cada um representa um grau da escala escolhida. Na escala padrão (Dó maior), os números seguem o teclado do piano na ordem natural.

NúmeroNotaComo soa
note(1)Dó (C)Início grave e estável
note(2)Ré (D)Um passo acima do Dó
note(3)Mi (E)Tom alegre e brilhante
note(4)Fá (F)Tom de transição
note(5)Sol (G)Nota marcante e forte
note(6)Lá (A)Nota suave
note(7)Si (B)Pede resolução (volta ao Dó)
💡 Para deixar a nota mais aguda, some um modificador: note(1^) sobe um semitom. Para saltar uma oitava inteira, use note(1[8+]).

Ritmo: por quanto tempo a nota dura

A função rhythm(número) acompanha a nota e define sua duração. Pense no número como "em quantas partes o compasso é dividido" — quanto maior o número, mais rápida (curta) é a nota.

rhythm(4)

Tempo padrão (semínima). Equivale a uma batida do coração ou um passo caminhando.

note(1) rhythm(4)
rhythm(1) e rhythm(2)

rhythm(1) dura o compasso inteiro. rhythm(2) dura metade dele.

note(1) rhythm(1) // segura o som
rhythm(8) e rhythm(16)

Notas rápidas, ideais para solos e trechos acelerados.

note(1) rhythm(8)
rhythm(pause n)

Silêncio: o instrumento espera antes de tocar a próxima nota.

rhythm(pause 4) // 1 batida de silêncio

Criando batidas com drum

A bateria não usa notas musicais — cada número liga uma peça diferente do kit.

1 Bumbo (grave) · 2 Surdo · 3 Tom-Tom
4 Caixa (seca) · 5 Abafo
6 Chimbal fechado (tss) · 7 Prato de ataque 

// Batida simples de pop/rock
play drum part {
    note(1) rhythm(8), // Bumbo
    note(6) rhythm(8), // Chimbal
    note(4) rhythm(8)  // Caixa
}

Juntando tudo: acordes e repetição

Combine notas em acordes e repita trechos inteiros sem reescrever o código.

chord()

Toca várias notas ao mesmo tempo, formando um acorde.

play piano chord(1, 3, 5) // Acorde maior
repeat(n)

Repete um trecho identificado por ID quantas vezes você quiser.

#meuTrecho.repeat(4) // Repete 4 vezes

Efeitos, articulação e mixagem

Tudo isso vai dentro do bloco atribute { } de um play, no formato propriedade = "valor".

type

O efeito sonoro do instrumento: delay (eco), wah (abafado), 8bit (retrô), distorted (rock) ou reverb (ambiente fechado). Tipo desconhecido vira normal automaticamente.

type = "distorted"
articul

staccato (nota curta), legato (fluida), marcato (acentuada), portato (staccato+legato) ou tenuto (segura até o limite).

articul = "legato"
fade

Transição de volume no início/fim do trecho. Use loud n% ou quiet n%, separando entrada e saída.

fade = in: loud 50%, out: quiet 50%
volume e speed

volume ajusta o quão alto soa (%); speed multiplica a velocidade do trecho, em % ou em nx.

volume = 70%
speed = 3x // 3× mais rápido

Variáveis de parte e múltiplos instrumentos

Guarde um trecho inteiro numa variável entre < > para reutilizá-lo em vários lugares, e toque a mesma melodia em vários instrumentos de uma vez.

<parte> part { }

Declara uma variável reutilizável. Se declarar de novo com o mesmo nome, o último valor vence.

<melodia> part {
    note(1) rhythm(1)
}

play piano {
    <melodia> // chama a variável
}
<parte>.repeat() / .tone()

Dentro de um play, a variável aceita as mesmas transformações de um ID: repetir e transpor.

play piano {
    repeat(4) {
        <parte>.tone(^)
    }
}
play instr1, instr2 { }

Toca a mesma melodia em vários instrumentos simultaneamente — cada um vira seu próprio canal.

play standard, synthBass {
    atribute {
        ids = "melodia", "baixo"
    }
    <melodia>.repeat(4)
}
💡 Faltou um ID na lista? O compilador gera um automático a partir do nome do instrumento, como #flute_auto_3, para você nunca perder a referência.

Loops mais poderosos

Além do repeat() já conhecido, a v1.1 traz formas mais compactas de repetir notas e ritmos.

repeatEach(n)

Repete cada nota do bloco um número de vezes; com vários parâmetros, cada nota usa um valor em ciclo.

repeatEach(4, 3) {
    note(1) rhythm(4), // 4×
    note(3) rhythm(4)  // 3×
}
xN — repetir nota/ritmo

Repete um valor específico dentro de note() ou rhythm() sem reescrevê-lo.

note(1, 2, 3x2, 4x4) rhythm(4)
// Dó, Ré, Mi (2×), Fá (4×)
[ ]xN — repetir um grupo

Repete uma sequência inteira de notas de uma vez.

note([1, 2, 3, 4]x2) rhythm(4)
// Dó Ré Mi Fá, Dó Ré Mi Fá
Ponto de aumento (.)

Dentro de rhythm(), o ponto multiplica a duração por 1,5×.

note(1) rhythm(4),  // normal
note(1) rhythm(4.), // 1,5× mais longa

Controle fino de oitava

Defina a oitava padrão do projeto e desloque grupos inteiros de notas de uma vez, sem repetir o modificador em cada uma.

stdOctave

Muda a oitava padrão de todo o projeto (o padrão é 4).

stdOctave 2 // ótimo para baixos
[8+n] — deslocamento livre

Além de + e ++, aceita qualquer número de oitavas.

note(1, 3, 5, 1[8+3]) rhythm(4)
// 3 oitavas acima!
Sufixo em grupo

Aplica a oitava a um acorde ou lista de notas inteira de uma vez.

chord(1, 3, 5)[8+] rhythm(8)
Bloco de escopo [8+] { }

Muda a oitava de tudo que está dentro do bloco — e blocos aninhados somam o deslocamento.

[8+] {
    chord(1, 3, 5) rhythm(4)
    note(1, 3, 5) rhythm(4)
}
