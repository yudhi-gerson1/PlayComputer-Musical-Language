Você não precisa entender de teoria musical! Copie o código abaixo, cole no transpilador e aperte o Play: 

compass standard
scale C major
bpm 120

// Toca uma sequência simples de notas no piano
play piano part {
    note(1) rhythm(4), // Dó (duração normal)
    note(3) rhythm(4), // Mi
    note(5) rhythm(2)  // Sol (duração longa)
}

1. As Notas Musicais (Super Fácil)

No PlayComputer você usa números de 1 a 7 para escolher as notas da escala. Na escala padrão (Dó Maior), cada número representa uma nota do teclado:

Número na Linguagem Nota Musical Como Soa?
note(1)Dó (C)Nota de início grave e estável
note(2)Ré (D)Um passo acima do Dó
note(3)Mi (E)Tom alegre e brilhante
note(4)Fá (F)Tom de transição
note(5)Sol (G)Nota marcante e forte
note(6)Lá (A)Nota suave
note(7)Si (B)Pede resolução (volta para o Dó)
💡 Quer mudar a altura da nota?
• Para deixar mais aguda (sustenido): note(1^)
• Para tocar uma oitava mais alta (agudíssima): note(1[8+])

2. Ritmo: Quanto tempo a nota dura?

Use a função rhythm(número) junto com a nota para definir a velocidade. Pense nos números como divisões do tempo:

rhythm(4) Batida Normal

É o tempo padrão (Semínima). Equivale a uma batida do seu coração ou um passo caminhando.

note(1) rhythm(4)
rhythm(1) e (2) Notas Longas

rhythm(1) dura o bloco inteiro (4 batidas). rhythm(2) dura metade do bloco (2 batidas).

note(1) rhythm(1) // Segura o som bastante!
rhythm(8) e (16) Notas Rápidas

Ideais para solos e ritmos acelerados. A nota toca bem rapidinho.

note(1) rhythm(8)
rhythm(pause n) Silêncio / Pausa

Faz o instrumento ficar em silêncio por um tempo antes de tocar a próxima nota.

rhythm(pause 4) // Pausa de 1 batida

4. Como Criar Batidas com a Bateria (drum)

A bateria não usa notas musicais do piano. No instrumento drum, os números ativam partes da bateria:

1: Bumbo (Grave) | 2: Surdo | 3: Tom-Tom
4: Caixa (Batida seca) | 5: Abafo
6: Chimbal Fechado (Tss) | 7: Prato de Ataque 

// Batida simples de Pop/Rock
play drum part {
    note(1) rhythm(8), // Bumbo
    note(6) rhythm(8), // Chimbal
    note(4) rhythm(8)  // Caixa
}

5. Juntando Tudo e Repetindo Trechos

chord() Acorde (Notas Juntas)

Toca várias notas exatamente ao mesmo tempo para criar um harmonia rica.

play piano chord(1, 3, 5) // Acorde Maior
repeat(n) Repetir Trecho

Repete um trecho musical quantas vezes você quiser sem precisar reescrever o código.

#meuTrecho.repeat(4) // Repete 4 vezes
