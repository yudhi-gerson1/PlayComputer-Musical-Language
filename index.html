1. Configuração Global e Estrutura

compass Global

Define a métrica de tempo/compasso da composição. Utilizado obrigatoriamente no topo do código.

compass 4/4
compass standard // Usa 4/4
scale Global

Define a tonalidade e a escala base (major/minor). O padrão do sistema é Dó Maior (C major).

scale C major
scale A minor
bpm Global

Configura o andamento da música em batidas por minuto (Beats Per Minute). Padrão: 120 BPM.

bpm 140
metronome Global

Ativa ou desativa a guia sonora do metrônomo (padrão TIC tac tac tac) durante a execução.

metronome active
metronome unactive

2. Comandos de Execução e Nota

play Execução

Instrução principal para emitir notas ou blocos num canal/instrumento específico. Se o instrumento for omitido, assume piano.

play standard note(1)
play synthBass note(1)
note() Função

Representa o grau da nota na escala ativa (1 a 7). Aceita modificadores de tom e oitava.

note(1^[8++]) // C#6 na escala C
chord() Função

Executa múltiplas notas simultaneamente para gerar acordes harmônicos.

chord(1, 3, 5) // Triada de Dó Maior
rhythm() Função

Métrica de duração da nota (1 = Semibreve, 2 = Mínima, 4 = Semínima, 8 = Colcheia, 16 = Semicolcheia). Suporta pausa.

note(1) rhythm(4)
rhythm(pause 4)
part { } Bloco

Agrupa uma sequência de instruções de um mesmo canal em um bloco estruturado, dispensando vírgulas excessivas.

play standard part {
    note(1) rhythm(1),
    note(2) rhythm(1)
}
= (Variáveis) Atribuição

Armazena notas, acordes, números ou trechos em identificadores para reaproveitamento no arranjo.

base = note(1)
play standard base

3. Controle de Fluxo, Atributos e Loops

atribute { } Atributo

Declara metadados de identificação (id e class) no início do bloco de uma parte.

atribute {
    id = "baixo"
    class = "groove"
}
escape(n) Sincronismo

Aplica um deslocamento temporal (delay) de n semínimas para evitar colisão e alinhar execuções concorrentes.

#baixo.escape(2)
repeat(n) Loop

Reaplica um canal por ID ou um bloco polifônico completo n vezes sequencialmente.

#trecho.repeat(4)
repeat(2) {
    #trecho
    #baixo.escape(2)
}
tone() Modificador

Aplica transposição de afinação (v, vv, ^, ^^) sobre uma parte inteira referenciada.

#trecho.tone(^)

4. Percussão Irregular (drum)

drum Instrumento

Canal percussivo onde os índices de note(n) disparam elementos do kit de bateria:

1: Bumbo (BOOM) | 2: Surdo | 3: Tom-Tom | 4: Caixa | 5: Abafo | 6: Chimbal Fechado | 7: Prato de Ataque | 8/9: Caixas Aguda/Grave 

play drum part {
    note(1) rhythm(8), // Bumbo
    note(6) rhythm(8)  // Chimbal
}
